## 维护

本仓库发布文件位于根目录，无需构建，GitHub Pages使用main分支根目录。

每题包含`id`、`subject`、`topic`、`title`、`stem`、4项`options`、从0计的`answer`、`translation`、`rule`、4项`explanations`、`source`、`authorities`及`extension`。保留既有ID；实质修改题意或选项顺序时换新ID，避免错配旧答题记录。更新`version`、`updated`和页面题量。不要提交个人学习记录、凭据或整本教材。

本地维护脚本与核验记录保留在LEC备考工作区`lec-study-bank/tools`、`lec-study-bank/qa`；公开站点只包含必要的七个发布文件。
