旧材料存在规则变化或参考答案歧义时，以明确题设及所列法源重写，不直接照搬书后答案。已注意近期证据规则修订、现行宗教条款框架、Dobbs、搜索扣押及知识产权规则等。传统普通法、联邦规则和州法不同测试分别说明。逻辑题的医学、生物学或气候材料只作题设推理，不作为现实科学结论。

## 维护

本仓库发布文件位于根目录，无需构建，GitHub Pages使用main分支根目录。

每题包含id、subject、topic、title、stem、4项options、从0计的answer、translation、rule、4项explanations、source、authorities及extension。保留既有ID；实质修改题意或选项顺序时换新ID，避免错配旧答题记录。更新version、updated和页面题量。不要提交个人学习记录、凭据或整本教材。

本地使用tools/build_600.py从冻结的100题基线和content中的四份增量合并重建，再运行tools/check.cjs。历史build_bank.py与expand_bank.py分别生成30／100题，不能用作当前发布的最终构建。核验记录保存在本地qa；公开站点只包含必要的七个发布文件。
